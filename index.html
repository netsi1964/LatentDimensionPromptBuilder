🧠 About the Latent Dimension Prompt Builder

When you see a person, your brain instantly builds a mental profile: he's about 178 cm tall, has brown hair, brown eyes… You unconsciously assign labels and values to describe what you're perceiving. These labels can be thought of as dimensions—they help you form an impression of the object in front of you.

Large Language Models (LLMs) like ChatGPT work similarly. They receive input—whether it's text, images, sound, or video— and process it across a wide set of latent dimensions. These are abstract categories that help the model understand and represent the "essence" of the input.

In this tool, the input (we call it context) might be a sentence, a paragraph, or even an image. The Prompt Builder then asks the LLM to describe how it perceives that context—just like you described the person above. It returns a JSON object containing:

  • The 20 most important latent dimensions used to "understand" the input
  • A category value for each dimension (e.g., "Calm", "Modern", "Muted")
  • A short explanation of each dimension
  • 10 additional values that show the spectrum that dimension can express
  • An example of how that dimension shows up in the current input

The result is a kind of semantic fingerprint—a structured impression of what the model saw, felt, or sensed in the input.

Once you have that expression, you can apply it to something else. For example: You could ask the LLM to generate an image of a rose styled with the same expressive dimensions as the man you described earlier.

In essence, this tool lets you extract the style or semantic aura of any object—and reuse it creatively across other inputs.
Because to an LLM, everything is just data.
